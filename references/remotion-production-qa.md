# 当前Agent / Remotion AI剪辑、实时预览与验收

## 1. 保留工程和统一时间轴

- 优先继续已运行工程与预览，先检查当前文件和用户并发修改；备份可恢复版本，不另起一套无关工程。
- 使用当前产品素材和真实fps。最新默认为1920×1080/60fps、MOV；已有工程按最终目标重算，用户明确规格优先。
- 为每条旁白建立cue ID，画面from/duration直接来自同一份timing数据。镜头文件、原入出点、成片帧、任务主题、证据类型写入剪辑表。
- 图片、GIF、录屏分别用正确媒体组件，逐帧驱动运动，避免CSS animation/随机时间导致非确定性渲染。动图确实播放，不用首帧截图假装动态结果。
- 完整剪辑先按 [四技能与镜头库](motion-library-workflow.md) 规划全片特效/转场/动效/音效，检查每个主段的实际采用及静止/无声理由。使用video-shotcraft卡前确认Gallery名称/style-key、读卡及准确demo源码；记录哪些参数保留，哪些随口播预算适配，哪些卡最终弃用。不可声称看过未取得的动态参考。

### 实录速率硬门槛

录屏默认1×，禁止低于1×的慢放，包括0.99×这类轻微慢放。按 `(source_out-source_in)/(output_out-output_in)` 审计实际速率，不只搜索显式 `playbackRate`；组件自动拉伸和EDL预处理也受约束。帧量化边缘按至多1个输出帧核对，播放率仍明确保持1×，不能把误差扩成拉长整段的理由。

录屏短于旁白时先向前/后扩充同一真实动作、合并相邻镜头或让镜头跨字幕；再考虑接清楚的真实结果静帧。禁止慢放、循环或复制帧冒充持续操作；不擅自改变已定稿声音。删等待/加速仅用于不承载关键动作的区间，原速保护项不加速。源片自身卡顿须换干净区间、重转码核验或补录，不能只补60fps标签。

此规则约束实录时间轴，不限制卡片动画的缓动、相机轻推或静帧阅读。已剪好且有保护要求的片段仍按原速保护。

## 2. 真实背景循环：静帧通过不够

已知失败：把背景放在镜头内部的Freeze结构，静帧渲染有背景，实时Studio却不挂载/播放video。

推荐结构：Main最底层只放一个真实背景视频Loop，解释段Base透明；音轨和镜头序列在其上；全片镜头不重置背景。单镜头预览用全局起始帧对齐背景相位。**这个限制是背景视频的故障教训，不是禁止对纯图片动画使用Freeze。**

验证：

1. 独立背景合成与用户原片核对纹理、色彩、时长。
2. 实际打开主合成；检查真实video已加载、ready、时间随播放变化。
3. 检查多个循环边界和镜头切换，不能只看0秒或一张still。
4. 确认没有另一个不透明Base/旧纯色底盖住背景；完整实录自然覆盖背景是正常。
5. 代理文件记录来源与转码，不额外叠未要求的滤镜/色罩。

## 3. 完整实录与聚焦

用源尺寸和contain比例完整放入画布。保留窗口、关键按钮、菜单与操作上下文。需要聚焦时，蒙版/高亮映射源坐标到成片坐标；轻推近须检查首尾不裁内容。

- 源素材自身的录制放大、浏览器缩放和运动模糊会改变控件位置。一个固定框不能沿用整段；优先换稳定源时段，或逐段更新坐标。
- 抽查Mac/Windows安装包行，不能源录屏放大后框到了另一行。确认高亮的是保存/继续按钮，不是旁边录制工具栏。
- 原生拖影/过渡帧不当稳定首页或阅读画面。进入首页须选清楚状态，保留至少0.5秒。
- 操作聚焦可以用约28%黑色蒙版作为本期起点；隐私遮挡必须不透明，不能拿聚焦透明度遮API Key。
- 浏览器密码浮层/账号信息的遮挡跟随实际源状态检查；不要漏出右侧字段，也不要盖住页面标题和模型控件。完整源UI与脱敏须同时成立。

## 4. 资源路径与预览交付层

- 视频/图片/字体放入可服务的public路径，通过框架静态资源机制引用。不要默认外部symlink可被Studio/打包器服务；本期曾出现真实文件可读但HTTP404，普通文件或已验证硬链接可用。
- 缺字体、白屏、媒体404、错误遮罩、背景不动，都是预览层失败。端口在监听或TypeScript通过不是完成。
- 密集墙面给5K原图建立符合最大显示尺寸的轻量代理，记录来源/尺寸，保留原件；不要让几十张原图重复解码拖垮预览。目标分辨率提高时重新核算显示像素，不能盲用太小代理。代理不擅自调色或裁切正文。
- 出现白块/超时先分清缺资源与解码压力；检查实际资源地址和错误，再从单并发短样开始。比较浏览器/GL/并发配置时一次只改一个因素，保留耗时与画面对照；修好瓶颈后再适度增加并发，不把提高超时当唯一修复。
- 复用原预览页，HMR更新后实际查看内容、当前合成、时长、字幕和媒体。不能交一个仍指向旧工程/旧导出的视频链接。
- 提供可暂停拖动地址、确切检查时间点、少量关键帧；截图落盘方便复核。用户要快时先交预览，不等待131秒整片长导出。

## 5. 全片语义检查

以语义单元对照：相关cue集合 → 观众此时需要理解的对象/动作/结果 → 可见任务/操作/状态 → 原文件/入出点 → 证据类型。一个镜头可绑定多句，也可先展示后解释；记录关联理由，不强制每句切换。类型区分实录、真实成品、真实截图、明确示意、待补录。

重点错误：

- 抽象“AI时代”配无关PPT；讲资料却放成品；讲大纲仍是另一主题或失败状态。
- “等待结果”已经露出完成稿；“原图”提前露出生成表情；“确认继续”没有对应按钮。
- “默认设置”仍停供应商列表；“Mac选dmg”高亮exe；“进入首页”仍是模糊放大过程。
- “PRD和原型”只给一个；连续过程里跨任务换题；真实失败提示当成功演示。
- 未录平台登录/创建密钥/首次启动，却用伪产品UI冒充实录；新建任务空首页被剪成已执行完成。

缺同主题干净录屏时可用真实成品内容整理“内容大纲示意”，显式标注，不伪造产品执行；多主题组图显式标注“成品示例”，不暗示同一任务连续产出。

## 6. 完整意思优先的镜头节奏

第一性原理：切点由观众是否建立因果关系决定，字幕句末不是切点命令。**禁止闪切，禁止动作没完成、结果没认清就切走。**

- 对每镜头记录“要理解什么/从哪里看到/完整动作结束帧/需要读懂的结果/允许切出的最早帧”。例如修改提示词须覆盖定位→实际键入→提交/保存→新状态；可从前一句就开始播放，延续到解释修改的下一句，不必按句复位。
- 可把前镜头延长、让一个真实动作跨多句字幕，或在后一句继续解释同一画面；关系应能用一句自然语言说明。提前展示不得泄露尚未执行的成功，延后也不能回到已修改前的旧状态。
- 按当前fps计算可见/稳定下限 `ceil(0.5*fps)`：30fps是15帧，60fps是30帧。此门槛只筛极短曝光；复杂操作、密集PPT或需要比较的页面必须按实际理解延长。每张成品/同组四页先完整可辨，再切下一主题；预算不足删状态/减少页数，不能加速闪完。
- 连续实录不强求动作期间完全静止，但动作结果需有识别余量；阅读可以使用清楚标为静态的真实结果。装饰粒子/光缝不算独立信息，也不能承载必要指引。
- 切镜前后检查实际尾帧/首帧：禁止重播上镜头起始poster形成“切走又回旧状态”，禁止以空背景/白块填加载，禁止剪掉中文输入法提交或保存过程。预挂载并用相邻真实状态衔接。
- 页面墙出入视口、最后一页残余时间也要检查；新增小图只露边角/一闪即走不算展示。页面墙可以持续柔和滚动，前景必须足够稳定供阅读。

先对照完整动作和语义，再检查时间表/切点前中后与1×连续片段。`validate_visual_timing.py` 只筛声明区间，不会判断已经看懂，也不证明画面真实可见。

## 7. 有边界的验收

一次批量检查 → 一次合并修复 → 一次针对修复确认；没有新问题不要反复微调/重渲染。出现真实语义错位、隐私泄漏、缺资源或黑帧时修复并补查相应位置。

| 层级 | 检查与记录 | 不能替代什么 |
| --- | --- | --- |
| 结构 | 类型检查、时间轴/字幕格式、总帧、资源、基线对比 | 美观与实际播放 |
| 全片静帧 | 每句中点，关键切换前/中/后，长句、源缩放、高亮/遮挡、手机小图 | 连续运动/声音 |
| 实时预览 | 实际Studio图像、字体、视频时间、GIF、背景循环，短段连续播放 | 整片导出文件 |
| 独立核查 | 按所用skill要求或复杂修改需要，给干净审查输入并记录问题与修复证据 | 制作者没有看过的声音和素材授权 |
| 连续视听 | 实际连续回看/听审配音、节奏、解码、背景接缝 | 不能用“已出静帧”冒称执行 |
| 正式导出 | 存在可解码文件、尺寸/fps/时长/音轨/体积、首尾与敏感区 | 终剪完成与发布不是同一状态 |

交付时按实际写“预览已更新/关键帧已查/整片已导出/连续听审未执行”等，不笼统全通过。音效只对准可见事件与实际起音，BGM不盖人声；时间轴变动需重新对齐。未改音频可用主轨哈希比较确认，没有听审仍不称声画终检完成。

## 8. 透明和成片导出

透明外部包装与整片合成分开。按需求选可编辑源码、轻量透明文件、预览或成片；文件后缀不证明alpha。先短样验证alpha解码、明暗底叠加、边缘与目标剪辑工具兼容。老案4K60、HEVC Alpha、ProRes4444仅作经验，不强制新项目照用。

正式视频只在用户需要时渲染，默认1080p60 MOV（H.264/AAC）；发布版与母版区分。必须按 [导出可靠性](export-audio-reliability.md) 检查实际解码帧数、逐帧显示时间戳和动态片段；仅平均60fps不能证明无卡顿。帧率/分辨率提升不能称素材新细节。交付源码时保留素材索引和本期缺录/示意/验证状态，别把本地绝对路径写成跨机器永久依赖。

改变帧率、正式导出或处理声音异常时继续读 [导出、音频与渲染故障处理](export-audio-reliability.md)。目标参数短样必须覆盖动效、视频/GIF和声音；不能只改合成fps或MP4标签。最终检查用实际文件，而不是渲染进度条。
