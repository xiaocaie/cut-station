# Portable production defaults

These overridable conventions contain no product identity, company case, author persona or fixed machine path.

| Dimension | Default | Adaptation |
| --- | --- | --- |
| Scope | Source-grounded tutorials/product demos; partial edits supported | Follow the actual brief for other formats |
| Narration | Explain optional Jianying before choosing | Existing audio, manual export or none; full-video mode does not imply consent |
| Subtitles | Semantic units separate from TTS input | Independently disabled; visual/provisional timing when no speech exists |
| Story | Concrete problem/result and evidence-backed steps | Genre-specific hook/ending; protect approved text |
| People | Recording plus optional voice; no automatic presenter | Authorized people in source footage may appear |
| Composition | Important UI large and readable | Focus/crop with context and actual readability checks |
| Material | Clear hierarchy, coherent typography, purposeful light/motion | Brand, background and style are project-specific |
| Fonts | Bundled Smiley Sans titles, Noto Sans SC dense Chinese, Space Grotesk Latin | Actually load and preserve OFL notices; choose for current language |
| Neon | Optional warm-white/olive glow preset | No mandatory neon; user art direction overrides |
| Motion | One main engine; selected vocabulary and corresponding SFX | Recommendations may be declined; reading sections may stay still |
| Playback | Real recordings at 1× | No padding with slow playback or fabricated loops |
| Rhythm | Complete semantic actions | 0.5s exposure/hold is only a floor; complex UI needs longer |
| Sound | Approved voice drives speech timing; independent music/SFX | No narration does not mean no music; preserve original speed |
| Export | 1920×1080, 60fps, compact H.264/AAC MOV | Current user/platform target overrides |
| Preview | Reuse actual project and working preview | Discover ports and tool APIs per environment |
| Completion | Separate technical checks and real viewing/listening | Tests do not prove full-film or cross-agent success |

See [installation](installation.md) and [compatibility](agent-compatibility.md). Scope does not authorize publishing, purchasing, account changes or unrelated installation.
