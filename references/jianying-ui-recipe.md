# Optional Jianying whole-text narration: semantic UI recipe

This describes the macOS desktop workflow. Historical private short-sample testing does not establish this public release on a new version, Windows, international CapCut or every agent. Re-check the current app/version and one real representative sample before committing a full track. This is guidance, not an executable universal UI adapter.

## Before opening the app

Explain the optional workflow, installed-app/desktop-access requirement, possible voice/account limits, and choices of existing audio, manual export or no narration. Reuse an already given answer. A narration-free project skips this page's operations entirely.

| Step | Semantic action | Actual success criterion |
| --- | --- | --- |
| Locate | Find the installed main app with the host's app/window inventory | Correct app and project; no hard-coded bundle path or coordinate |
| Project | Reuse this project's draft, or create a dedicated voice draft | Unrelated user drafts preserved |
| Text | Text → New text → add Default text | One complete clip for this generation; bounded chunks only with explicit user/UI evidence |
| Paste | Select its real content editor, replace with complete TXT once | Start/end, terms and full text match; one object |
| Read | Open narration, use agreed voice/speed, generate once | Generation finishes and a continuous waveform appears |
| Export | Audio-only export to the project's chosen path | Correct format/name/directory; visible completion |
| Validate | Probe and decode the real exported file | Real audio stream/duration and complete decodability |
| Resume | Return to the agent for real timing/captions/editing | Output follows actual audio, not a pre-estimated duration |

## Host adaptation

Use actual accessibility/screenshot controls supplied by the host; no cua API is required by the skill format. Discover the UI before input. If accessibility fails, inspect the current screenshot and try a targeted repair. Do not reuse stale coordinates or operate unrelated windows. Without desktop tools, give the user this checklist and the whole TXT, then continue from their real export.

Available formats and voice limits vary. MP3 exported and decoded to PCM remains MP3-sourced audio, not a native lossless export. Never promise unlimited text. A confirmed user/UI limit permits a few semantic chunks using prepare_voice_text.py --max-chars with its evidence; keep voice/speed, preserve all text and join real exports before timing. Never split by display-caption cues or retry unchanged over-limit text.

Save current project/version and actual text, voice, waveform, export and file evidence locally. Do not bundle screenshots, user audio or private evidence into the skill. No account purchases/settings changes are implied.
