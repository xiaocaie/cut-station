# MG 动效配方与视觉预设

在 CutStation 请求里说出效果名称、目标镜头和素材即可调用。可以只指定一个动作，也可以组合一个动作和一套视觉预设，例如「第二章开头用章节卡侧翻，套暖白纸卡预设」。复用项目当前的素材、字体授权、画幅和阅读节奏。下文的时长和数值是调校起点，像素参数以 1920×1080 为基准。

对「使用适合的动效」走 [素材驱动选型](adaptive-motion.md)，先检查实际镜头和文字的适用性。平直截图卡墙、掠卡换场、全屏翻页展廊及分拍标题的调用见同一指南。

## 组件选择与自动调用

从 [MG 逐帧组件](../assets/effects/mg-motion.mjs) 复用绘制实现。两套预设由 `MG_PRESETS` 提供，可套在任一组件或单独取色彩与字体配置。每个项目需要说明素材身份、实际镜头范围和需要替换的内容。

| 组件 ID | 点名时用 | 只描述画面时匹配 |
| --- | --- | --- |
| `chapter-flip` | 章节卡侧翻 | 编号卡立起来向侧面翻，在最窄时切进下一页 |
| `page-to-card` | 网页缩入卡片／样片推入全屏 | 页面全貌缩到一旁腾出对比空间，或从卡里推近进入全屏 |
| `branch-cards` | 主卡展开与分支连线 | 一个中心对象派生多个节点，沿线逐个接起来 |
| `grid-roll-stamp` | 填格、滚数与盖章 | 格子逐个填亮、数字滚到对比值，或用章印落定结果 |
| `data-score` | 数据生长与分数尺 | 条形从基线长高、阈值出现，或光点与分数一起在刻度轴上移动 |
| `gallery-2-5d` | 2.5D 卡片展台 | 三张卡先虚焦托住大字，然后恢复清晰、带视差与倒影错层排开 |

点名时优先采用指定组件、变体和预设。只描述画面时，按该镜头的主要视觉动作选最匹配的组件，无需再确认名称。先按语义理解用户想看的变化，`resolveMgEffect(description)` 可辅助识别常见表达和别名。如一句话包含多个独立的动作，按实际分镜拆开再匹配。描述较泛时，依据镜头任务选择，保留适合静止阅读的段落。需要动效时绘制本期素材并记录组件 ID、预设、动作时间和检查帧。

## 1. 章节卡侧翻

- **调用**　「开场目录进入第二章时用章节卡侧翻，第二张卡向左翻，接第二章的网页全貌。」
- **动作顺序**　目录卡先稳定陈列 → 目标卡提到前层 → 卡面绕竖轴转向侧边 → 最窄时接下一画面 → 新场景落定供阅读。若本章之后返回目录，可让原卡在原槽位显示本章结果。
- **可调参数**　目标卡、翻转方向、卡片锚点、透视、接入帧和落定停顿。总时长从 0.35–0.55 秒试起，在约 80–90 度的窄卡面上找切点。
- **成片检查**　看翻前、最窄和接入后各一帧，再按 1× 看一遍。卡的位置可追踪，画面连续，进入新章后卡面和字形朝向正确。

## 2. 网页缩入卡片／样片推入全屏

- **调用**　「全屏官网缩入左侧截图卡，落定后在右侧展开对比。」也可说「第三张样片从展板推入全屏，从 00:08 开始播。」
- **动作顺序**　缩入时先展示网页全貌 → 连续缩放并移向版式锚点 → 随缩放调圆角 → 到位后再揭示图解。推入时先选中展板上的样片 → 沿该卡的焦点推近 → 边框越出画幅时接同一素材的全屏画面 → 从衔接时点继续播放。
- **可调参数**　缩入或推入方向、卡片槽位、素材焦点、源时间点、圆角、裁切和停顿。运动从 0.45–0.8 秒试起，按 [视觉规范](visual-direction.md) 设置实录占比。
- **成片检查**　对齐切点两侧的同一标志、文字或画面元素。网页焦点和所需上下文保留，样片画幅与时间连续，落定后图解有足够阅读空间。

## 3. 主卡展开与分支连线

- **调用**　「把总览做成主卡展开与分支连线，上面一张主卡，下面四张模块卡，按左到右连接。」
- **动作顺序**　主卡居中亮相 → 缩至上方锚点 → 子卡依序落位 → 曲线沿父节点向子卡描画 → 必要的关系标签亮起 → 总览停留。子卡较多时可按组入场。
- **可调参数**　节点数量、排列和进场顺序、曲线弧度和线宽、描线速度、错峰间隔和停留。整体展开可从 0.6–0.9 秒试起，相邻子卡初始错开约 50 毫秒。
- **成片检查**　最终连线的两端都贴住目标。动作中可分辨主次关系，落定后最远节点和最长标签在手机画幅里仍清楚。

## 4. 填格、滚数与盖章

- **调用**　「用填格和滚数对比三档，最后给推荐档盖章。」也可直接说「只做数字滚动」或「在结果右上角盖章」。
- **动作顺序**　卡片先沿共同基线到位 → 方格按量填充、数字滚向目标 → 结果停稳 → 需要强调时描边或落印章。数字槽做局部裁切，让改变的数字位独立滚动。
- **可调参数**　档位与数值、格数与映射、起止值、数字位数、滚动时长、印章文字、落点、倾角与力度。盖章可从 115% 缩到 96% 再回到 100%，合计约 0.22 秒。
- **成片检查**　最终格数和结果值与数据一致，千分位、小数点和单位位置稳定。印章落下和停住时都避开名称及关键数值。

## 5. 数据生长与分数尺

- **调用**　「左边两根柱从 0 长到目标值，显示达标线。」或「用 0–10 分的分数尺，把光点和大数字从 5.2 推到 7.8。」
- **动作顺序**　先建立基线和刻度 → 柱条沿基线生长，或光点沿尺移动 → 数字同步更新 → 最后点亮阈值、结果或关键对照 → 停留供比较。
- **可调参数**　初值和目标值、量程、单位、基线、阈值、轴方向、间距、增长顺序和速度。单次增长从 0.35–0.6 秒试起，光点、条形和数字共用同一进度。
- **成片检查**　比较对象使用一致的量纲和基线，光点落点与刻度值匹配。暂停在中间帧和结束帧，核对数字与形状保持同步，阈值出现后留有读数时间。

## 6. 2.5D 卡片展台

- **调用**　「片头用 2.5D 卡片展台摆三张成品，中心卡最清楚，底下有淡倒影，右侧评论微倾。」
- **动作顺序**　背景先建立空间 → 主卡和配角卡按深度进场 → 前景标题、标签或评论按需浮入 → 镜头小幅推移，让三层产生差速 → 主卡落定。需要倒影时，将卡沿底边镜像并向下渐隐。
- **可调参数**　卡片间距、层深、倾角、镜头推移幅度、前后景速度、景深、倒影渐隐长度和透明度。普通陈列可从 4–10 度的轻倾角和 8%–18% 的倒影透明度试起。
- **成片检查**　正常速度能分出前后层，主卡仍清晰，前景标签避开主要内容和字幕。倒影跟随卡的位移与缩放，接地边保持对齐。

## 7. 暖白纸卡预设

- **调用**　「给这组评测卡套暖白纸卡预设，保持青绿连线和珊瑚红的强调色。」
- **动作顺序**　铺暖白背景 → 放奶白卡面与暖灰软影 → 建立展示字、标签和字幕三层 → 动作落定时加入青绿连线、珊瑚红状态或强调 → 统一后续镜头的材质和色彩角色。
- **可调参数**　底色、卡色、阴影偏移和模糊、圆角、状态色与黑色字幕描边。英文展示字可选高对比衬线，Baskervville 是近似选型，由项目提供字体文件。中文和密集说明可用包内 Noto Sans SC，字幕可用白字配黑描边。
- **成片检查**　将关键帧缩成手机预览尺寸。浅色卡边可辨，数字和小字清楚，强调色稳定指向同类状态。按 [字体说明](fonts.md) 核对实际载入的字形和字号。

## 8. 暗场展台预设

- **调用**　「给三张样片和标题套暗场展台预设，保留低亮度点阵，蓝光只在主卡背后。」
- **动作顺序**　铺深色底和低亮度点阵 → 在当前主体背后加局部蓝光 → 将模糊、倒影放到指定空间层 → 单独放置清晰标题、数字和字幕 → 需要强调时给关键词加渐变填色或细下划线。
- **可调参数**　底色、点阵间距和对比度、光晕的半径和强度、模糊半径、渐变方向、倒影强度与字重。英文与数字可用包内 Space Grotesk 粗字重，中文可用 Noto Sans SC 粗字重。
- **成片检查**　看最暗、最亮和景深切换的帧。暗部层次可辨，字芯清楚，倒影和光晕让主体更集中，标题和字幕有足够对比度。按 [字体说明](fonts.md) 验证本地字形加载。

## 接入制作工程

将 [mg-motion.mjs](../assets/effects/mg-motion.mjs) 复制到项目的效果模块目录。Remotion 项目同时复制 [mg-motion-remotion.mjs](../assets/effects/mg-motion-remotion.mjs)，将两个文件放在同一目录。以下示例用本期素材和标签套用暗场展台。

```jsx
import {Sequence, staticFile, useVideoConfig} from 'remotion';
import {CutStationMgMotion} from './effects/mg-motion-remotion.mjs';

const galleryContent = {
  galleryHeading: '本期作品',
  galleryEmphasis: '三个案例',
  galleryLabels: ['资料整理', '流程演示', '成果展示'],
};
const gallerySources = {
  gallery: [
    staticFile('cases/notes.png'),
    staticFile('cases/process.png'),
    staticFile('cases/results.png'),
  ],
};

export function CaseGallery() {
  const {fps} = useVideoConfig();
  return (
    <Sequence durationInFrames={Math.ceil(7.1 * fps)} premountFor={fps}>
      <CutStationMgMotion
        id="gallery-2-5d"
        preset="暗场展台"
        duration={7.1}
        content={galleryContent}
        sources={gallerySources}
      />
    </Sequence>
  );
}
```

普通 HTML 和 HyperFrames 由项目当前的主时间轴调用 `createMgMotion({id, preset, duration, content, style})`。在挂载时创建一次实例，每帧调用 `instance.draw(canvas.getContext('2d'), localSeconds)`。`localSeconds` 从本镜头起点计时，可乱序取帧。默认比例为 16:9，`draw` 可传入 `{x, y, width, height, fit}`，`fit` 支持 `contain` 和 `cover`。重用同一画布时由宿主明确何时清空或叠图。

`duration` 以秒为单位，未给值时沿用预览时长。它等比重定时全段，注意留够落定与阅读时间。传入 `content` 可关闭默认示例字幕，使用 `caption: '自定义字幕'` 显示本期配字，或用 `caption: false` 交由本期字幕轨。原样调用保留预览中的示例。以下选项可按镜头覆写。

| 组件 | 可复用参数 |
| --- | --- |
| 章节卡侧翻 | `cards` 传 1–9 个标签，`selectedCard` 从 0 开始，`flipDirection` 选 `left` 或 `right`，`page` 指定接入后的画面。 |
| 网页缩入卡片／样片推入全屏 | `pageDirection: 'shrink'\| 'expand'\| 'roundtrip'` 选择方向，`page` 是同一源画面，`tiers` 与 `dockTitle` 描述旁侧对比，`showComparison` 控制是否出现。 |
| 主卡展开与分支连线 | `projectName` 是主卡标题，`cards` 传 1–9 个节点，`branchChips` 传最多两个说明标签。 |
| 填格、滚数与盖章 | `tiers` 传 1–3 个 `{label, value, filled}`，`value` 为非负整数，`filled` 为 0–20。用 `prefix`、`unit`、`gridUnit` 定义显示单位，`highlightTier` 从 0 开始，`stamp` 指定章印。用 `meter` 提供第二组 `{left, right, leftLabel, rightLabel, label}` 数字牌。用 `statusMode` 的 `grid`、`roll`、`stamp` 单独播放相应动作，`all` 播完整段。传实际档位时按本期要求提供章印及数字牌。 |
| 数据生长与分数尺 | `scoreMode: 'bars'\| 'rail'\| 'both'`，`barValues` 传 1–12 项，按需传 `barLabels`、`barMax`、`barUnit`、`threshold`。只传柱数据时默认只播放柱图，只传起止分数时默认只播放分数尺。分数尺使用 `scoreRange`、`scoreFrom`、`scoreTo`、`scoreDecimals` 及可选结果文案 `scoreResult`。 |
| 2.5D 卡片展台 | `gallery` 传三张画面，`galleryLabels`、`galleryHeading`、`galleryEmphasis`、`galleryTitle` 配字幕和标题，`tilt`、`blur`、`reflectionOpacity` 调节透视、虚焦与倒影。 |

原生 Canvas 接法的 `content.page` 与 `content.gallery` 接受已解码的图像。需要时间同步的素材，由宿主将当前帧作为 `draw(ctx, localSeconds, {media: {page, gallery}})` 传入，每次只传本镜头使用的字段。Remotion 适配器的 `sources.page` 和 `sources.gallery` 接收已解析的静态图片地址，等待图片解码并绘制后再继续渲染。需要实际视频时由工程的媒体管线提供同步帧。

`preset` 接受 `paper`、`stage` 或对应中文名。以 `MG_PRESETS.paper`、`MG_PRESETS.stage` 取用背景、图层和字体配置，`style` 可以覆盖如 `line`、`accent`、`display`、`sans`。按 [字体说明](fonts.md) 安装或加载工程实际用到的字形。检查默认进入、中间过程和落定帧，再用本期真实素材验证尺寸、可读性和 1× 连续播放。
