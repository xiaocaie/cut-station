# 口播文字与音效：从参考拆到可执行规则

适用：口播、AI教程、产品演示的文字入场、关键词强调及音效编排。完整剪辑必须设计丰富的文字/镜头动效与匹配音效，优先按 [Shotcraft执行](motion-library-workflow.md) 选材；本表用于语义搭配，不是要求每个字幕都套效果。明确禁音/直切的局部指令优先。以下为可适配的通用搭配示例。

## 实际参考中值得学的动作关系

| 定位 | 参考中可见的关系 | 底层用途与可迁移做法 |
|---|---|---|
| A约0–1秒 | 打字式逐步出现，搭键入声 | 表示“正在形成”的输入；适合短网址/提示词，不给整条旁白机械打字 |
| A约1–2秒 | 滚入，配胶片滚动类声 | 连续位移配连续摩擦/转动；进入阅读状态后声音也应收住 |
| A约2–5秒 | 弹入、弹簧、弹弓分别配短弹出/弹性声 | 把视觉当有质量的物体；声音突出起跳或落定，回弹只做一次 |
| A约7–8秒 | 折叠，配纸张抖动 | 声音材质解释运动，不是所有卡片都配电子叮声 |
| A约12–16秒 | 颗粒飘动、左移、收拢、开幕各有不同质感 | 粒子、位移、聚合、揭幕是不同信息动作；先选动作再选音色 |
| A约17–21秒 | 放大震动、渐显、吸入、模糊发光分别配不同短声 | 大小/清晰度变化有强弱，不能全用重低音；渐显可用轻微水滴/高频点 |
| A约22–27秒 | 下露、斜向弹入、闪动、溶解、模糊、上弹 | 方向、加速度、材质与情绪共同决定声音，不以预设数量取胜 |
| B约0–2.4秒 | 普通钩子先出现，重点另用红色与位置突出 | 同一画面保留主次；增强的是新增重点，不把旧字一起反复弹 |
| B约2.4–4.8秒 | 疑问与突然转折，偏紧张/夸张的音色 | 声音可提供情绪标点；只有真实反问或转折时才采用 |
| B约4.8–6.8秒 | 信息展开；数据词另突出，配“开始/收银”类提示 | 新信息与结果反馈分开；“免费/价格/数据”可选择清脆点声，但不凭空增加钱币动画 |
| B约6.8–9秒 | 心跳、搞笑反转各有专属动作和声色 | 这是喜剧/情绪用途，不宜硬放在API设置等专业操作段 |
| B约9–13秒 | 尴尬、知识点、次重点、晕开分别处理 | 情绪、知识、层级不是同一个问题；知识点用清晰显现，次级内容用较小幅度 |
| B约13–15.6秒 | 单字放大强调 | 少数字可强调，整句保持完整可读；不要每个字分别发声 |

## 第一性原理：先给注意力分配职责

**叙事在说什么 → 观众此刻应看哪里 → 元素为什么移动 → 哪个瞬间需要声音 → 落定后读多久。**

声音和位移是两条抢注意力的通道。两者指向同一动作，观众会把它们合成一个事件；不同步或不停触发，会变成额外负担。网感可以来自一次准确的“弹出—落定—停顿”，不依赖持续吵闹或塞满流行梗。

1. **信息层级优先。** 开场/观点转折可强；章节与成品中等；操作提示轻；普通字幕可无声。只有信息或状态真的变化才建立事件，不把每条配音当音效点。
2. **质量与材质一致。** 重字用短低频冲击；弹卡用短弹性/气泡；纸/大纲用摩擦展开；横移用有方向的空气声；按钮用干触点；完成用短和声；成品光泽用少量高频颗粒。
3. **峰值对动作，不只对文件起点。** 有前摇的掠过声，声峰对齐运动最快处；点击/落地声峰对齐点击或收定。记录 `actionFrame` 与音源自身 `peakFrame`，起播帧由两者差得到。剪辑时按实际动作微调，不只按句首自动铺声。
4. **变化来自语义。** 先决定是否需要音效，再选族，再在同族里选不同材质。不是随机轮流用不同音色，也不是把同一声音变调后宣称新增一类。
5. **安静是节奏。** 等待、阅读、长说明不循环滴答，不逐字点击；同组卡片在完整可读后切换通常合并一次过渡声；不允许以声音节奏为由闪切。连续相同事件先删减，之后才考虑替换。
6. **有配音时优先保证字音清楚。** 音效要与实际旁白/BGM混听；无配音按本期声音设计检查，完整无声要求则跳过音效。短而清楚的瞬态更容易留出空间，素材本身很响时先降增益；参考音轨响度不照搬。

## 可执行动作词典

以下为30fps附近的起步参数，随语速、字体、镜头时长调整，不是每期硬指标。保留当前字幕内容、配音和产品视觉方向。

| 语义 | 文字动作起步值 | 声音与同步 | 收定 |
|---|---|---|---|
| 强观点/开场重字 | 6–10帧，1.15–1.20缩到1；仅一次微回弹 | 短冲击/干脆落点；对齐首个收定 | 不持续震动/闪烁 |
| 反问/提醒 | 8–12帧，0.8放至1.03再到1 | 弹性短声，克制使用夸张综艺声 | 重点词留下，其他字保持静止 |
| 章节标题 | 8–12帧，遮罩上露/24px短移 | 轻扫过，可完全静音 | 完整字芯，不留拖影 |
| 同组卡片 | 10–14帧，逐卡错开3–5帧 | 整组一个展开/气泡声 | 不逐卡“叮叮叮” |
| 大纲/信息展开 | 8–12帧，轻折叠/遮罩展开 | 纸张或轻摩擦，峰值落在展开中段 | 说明文字可不动 |
| 短输入 | 约0.4–0.8秒成组显现 | 一小组键声，无声也成立 | 留足完整字符串阅读 |
| 关键词 | 4–7帧，小幅放大或色彩强调 | 只在有价值的点配清脆声；不每字配音 | 同一句只选一处，避开字面跳动 |
| 普通字幕 | 0–6帧，短移8–12px/轻显 | 默认无声 | 动画不能吃掉阅读预算 |
| 完成确认 | 轻显/收定，不伪造新通知 | 短双音/明亮收尾 | 先确认实录已出现对应状态 |

稳定可读状态至少0.5秒；字幕很短时，缩短或取消动画，而不是缩减阅读时间。禁止为了表现音效新种类而把所有动作加进一条视频。
