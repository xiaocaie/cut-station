# Writing and publication handoff

Write for the actual audience, source material and requested channel. Keep the opening, evidence, demonstrated result and next action consistent. A tutorial should make a real next step clear; a demonstration should show the claimed behavior. Preserve approved text and voice in a style-only edit.

Titles and covers use concrete objects and benefits the actual film supports. Do not invent time savings, quality rankings, user counts or interaction results. Separate source operation time, generation wait, production time and final running length. Comparisons require equivalent inputs/settings and real evidence.

A publication package may contain an accurate title, short description, platform-specific body, relevant credits, cover and source/project handoff. Produce only requested assets. Layout, aspect ratio and tone follow the project, not a fixed personal brand. Avoid copying a creator's catchphrases or importing a historical company's CTA.

Check private UI regions, account names, company documents, internal URLs/tokens, source permissions, music/font attribution and export properties before delivery. Refer to the public-release guide for distributing the skill itself. Preparing a post is not authorization to publish or send it; use actual user authorization.
