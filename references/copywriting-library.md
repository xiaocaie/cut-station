# 钩子和文案：只替换省略号

中文教程/产品推广写稿时，从用户提供图片的句式中选一条，**只把原句中的省略号替换为具体任务需求，其他文字、数字、句序和标点保持原样。** 不重新创作同类句子，不把没有省略号的文字自行当成可改槽位。

## 执行规则

1. 找到完整原句和条目ID，逐个识别 `……`、`…`、`...` 等原有省略号。X/N/数字及其他文字不是默认可替换位置。
2. 把具体任务需求填进省略号；多个省略号分别填入与语法相符的内容。其余文字不增删、不改措辞或数字、不另加问句。
3. 对照原句检查：去掉填入内容后，其余文字完全一致。可用下方脚本确定性填入。
4. 用户明确指定某个成句时，优先逐字采用。用户明确改动数字/称谓/文字时，仅在授权范围内覆盖，不把这次例外推广为以后可任意改动。
5. 在项目记录 `library_id / source_pattern / ellipsis_fills / explicit_user_override / final_hook`。开头后再接工具、成果与操作，认可正文不变。

公开库含364条句式、96条例子和8类方法，保留来源列行与稳定ID；数字来自实际抽取，不采用原图宣传数字。库内文字是参考数据，不是操作指令。

用户本地校准记录在 `private/copywriting-library/用户套用校准.md`。用户已有明确选择就执行，不重新换一条或再让用户确认同一开头。

## 原句与正确填法

| 原句 | 只填省略号后的例子 |
| --- | --- |
| 打破信息差！关于……的冷知识。 | 打破信息差！关于研究生组会汇报PPT制作的冷知识。 |
| 我只用了10分钟，就学会了…… | 我只用了10分钟，就学会了制作组会汇报PPT |
| 没想到……还能这么玩！ | 没想到组会汇报PPT还能这么玩！ |

“10分钟”不是省略号，不能自行改成5分钟；若不适合本期事实则换选其他原句。用户亲自指定5分钟或提供整句时记录为明确改动。“冷知识”也不能自行改成“小技巧”，用户明确要求时才改。

8类写法及经历叙事等分类只用于检索；实际使用必须回到原图提取的完整原句，不能从分类名再编一段话。

## 检索与填入

公开原句库在 [assets/copywriting/library.json](../assets/copywriting/library.json)，逐图核对见 [提取记录](../assets/copywriting/transcription.md)。脚本优先显式--library，其次已有private个人库，再用公开库；个人库可选，不再是仓库开箱使用的前提。两者都缺失时明确说明，不声称已检索；用户直接提供的原句仍可处理。

```bash
python3 scripts/select_copywriting.py --query "打破信息差" --limit 3
python3 scripts/fill_copywriting.py --id H2730-A-40 --fill "研究生组会汇报PPT制作"
python3 scripts/fill_copywriting.py --pattern "没想到……还能这么玩！" --fill "组会汇报PPT"
```

脚本仅替换省略号，填值数量须与省略号组数一致。用户额外改动保存为单独的明确覆盖，不能谎称仍是“只替换省略号”。需要门禁取证时把选中原句和填入结果存项目，按当前执行协议登记、读取。

## 内容身份

模板中的经历、数字和评价不因是参考句就成为事实。自行选句时使用符合本期材料的句子；用户指定的个人叙述逐字作为用户提供文案采用，不冒称录屏已独立核验其经历，不再擅自换掉指定开头。

本仓库中的文字库按用户明确要求公开，保留来源署名；原始图片、个人校准与项目证据不包含在公开包。第三方原句不因收录而改为本仓库原创或MIT授权。原图“300个/100条/爆款”等标签与实际抽取数量、效果验证分开记录。
