# 小菜蛾剪辑工坊

**给几句需求和一份素材，用 Codex 或 Claude Code 剪出一条视频。** 录屏、PPT、图片都可以用来做教程或产品演示。先审字幕稿，需要时用剪映配音，看到初稿后按你的反馈修改，最后导出成片。

[English](README.md) · [快速开始](#快速开始) · [四步工作流](#四步工作流) · [交付物](#交付物)

## 为什么做小菜蛾剪辑工坊

现有剪辑 Skill 往往各管一段：有的写文案，有的做动效，有的处理素材。换工具时，文案、音频和时间轴还得重新对接，做到预览也可能卡在最后的导出。

小菜蛾剪辑工坊把文案、剪映配音、素材剪辑、画面动效和成片导出串成一套流程。确认后的文案和配音直接带入后续剪辑，预览、修改和交付沿用同一套视觉与制作标准。同一批教程或演示视频也可以复用这套流程，统一字幕、画面风格和导出规格。

一次项目制作记录中，单条视频的制作耗时从 **180 分钟缩短至约 40 分钟**，**降低约 77.8%**。实际用时会随素材、剪辑复杂度和修改轮次变化。

## 快速开始

### 1. 安装

下载或克隆仓库，在仓库目录里运行对应的命令（需要 Python 3.9+）：

```bash
git clone https://github.com/xiaocaie/cut-station.git
cd cut-station

# Codex
python3 scripts/install.py --agent codex

# 或 Claude Code
python3 scripts/install.py --agent claude-code
```

安装时可以选装推荐的剪辑和动效 Skill，已有的可以复用。安装后如果找不到小菜蛾剪辑工坊，重新加载 Agent。其他 Agent 和手动安装方式见[安装说明](references/installation.md)。

### 2. 发素材，说清楚要做什么

上传录屏、图片、PPT 等素材，或提供 Agent 能访问的本地路径。有写好的文案、旁白或原工程，也可以一起给。第一条需求可以直接这样写：

> 用小菜蛾剪辑工坊把这些录屏和 PPT 剪成一条面向新手的教程。开头先告诉观众能学到什么，再用实录讲操作。字幕稿先给我审；确认后用我选的剪映音色配音，剪一版给我看，定稿后导出 1080p、60 帧成片。

## 四步工作流

| 步骤 | 你要做什么 | 小菜蛾剪辑工坊会做什么 |
| --- | --- | --- |
| **1 · 审字幕稿** | 用几句话说清楚主题、受众和想展示的内容，上传视频、图片等素材。 | 根据真实素材写一版有网感的开头和可修改的字幕稿（口播文案）。[钩子库](assets/copywriting/library.json)有 364 条开头句式：选中一句后，直接把省略号换成你的具体内容。 |
| **2 · 剪映配音** | 确认字幕稿并选择音色。剪映提示登录时再登录；已有音频或不需要配音，就跳过这一步。 | 剪映桌面端可用时，把确认好的完整文案导入剪映并生成配音；支持单独导出 MP3 时，将 MP3 带回 Codex 继续剪辑。字幕时间轴按实际声音对齐。 |
| **3 · 看初稿** | 告诉 Agent 哪些操作、页面或结果一定要展示。 | 自动完成素材剪辑、字幕排版和画面制作，按内容加入重点标注、转场、动效或音效，先给你一版可播放的初稿。 |
| **4 · 修改并导出** | 按时间点反馈，或者直接说明要改哪句、哪段画面。 | 按反馈迭代；局部修改时保留已确认的内容。定稿后检查并导出，默认 **1080p、60 帧 MOV**，也可以指定其他规格。 |

## 交付物

| 你想要 | 可以拿到 |
| --- | --- |
| 一条完整教程或产品演示 | 可审核字幕稿、配音（可选）、对齐后的 SRT、剪辑预览和成片。 |
| 先写稿或只做字幕 | 单独交付字幕稿，或根据已有旁白输出 SRT。 |
| 只改一处 | 提供原工程后，可以单改一条字幕、一个画面提示或一段镜头。 |
| 留着自己继续剪 | 可以一并要可编辑工程、配音和字幕文件、素材清单。 |
| 同一系列的多条视频 | 复用统一的画面风格与导出规格，逐条预览，按批交付。 |

## 工具与使用条件

只写稿时，提供素材即可。制作成片时，Agent 需要能读取本地文件并运行命令，同时准备 FFmpeg/ffprobe 和选用的渲染工具。只有走剪映配音路线时，才需要剪映桌面端；可选音色和导出方式以你的客户端为准。

| 工具 | 用在哪一步 |
| --- | --- |
| [Video Use](https://github.com/browser-use/video-use) | 处理录屏等原始素材和语音时间。 |
| [Remotion Agent Skills](https://github.com/remotion-dev/skills) 或 [HyperFrames](https://github.com/heygen-com/hyperframes) | 制作字幕、画面包装和动效，按项目选一条渲染路线。 |
| [Video Shotcraft](https://github.com/Vincentwei1021/video-shotcraft) | 为镜头、转场和音效挑选合适的做法。 |
| 剪映桌面端 | 把已确认的文案生成配音，回到剪辑项目使用。 |
| FFmpeg / ffprobe | 处理素材，检查导出文件的格式、尺寸、帧率和解码。 |

安装脚本负责安装 Skill 文件，桌面应用和渲染环境按实际路线准备。详见[使用条件](references/agent-compatibility.md)和[安装说明](references/installation.md)。
